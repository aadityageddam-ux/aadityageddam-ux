# Aaditya Geddam

Health Data Science at The George Washington University (expected May 2028). Learning how cells can be made young again: partial reprogramming with Yamanaka factors, and the machine-learning models built around it.

First author, [*The Journal of Liquid Biopsy*](https://doi.org/10.1016/j.jlb.2023.100009) (2023). Second author on a vestibular-reflex manuscript from an NIH-funded neurology lab (in preparation).

[Website](https://aaditya-site-zeta.vercel.app) · [LinkedIn](https://linkedin.com/in/aaditya-geddam)

## Selected work

- **[hdac1-qsar-gnn](https://github.com/aadityageddam-ux/hdac1-qsar-gnn)**: fingerprint vs graph models for HDAC1, HDAC6 and hERG bioactivity. On all three targets, the train-test split changed which model looked better.
- **[apoe-protein-lm](https://github.com/aadityageddam-ux/apoe-protein-lm)**: does a protein language model recover the APOE longevity association? ESM-2 ranks the alleles in reverse, which fits ε4 being the ancestral allele.
- **[hds-lab3-messy-parsing](https://github.com/aadityageddam-ux/hds-lab3-messy-parsing)**: regex vs AI-assisted cleaning of messy clinical and FASTA data, scored against a ground-truth table.
- **[PUBH4201_Lab2](https://github.com/aadityageddam-ux/PUBH4201_Lab2)**: differential expression of dexamethasone-treated airway smooth muscle cells (GSE52778), with a volcano plot and known-gene check.
