# Aaditya Geddam

Health Data Science at George Washington University (expected May 2028). I build open tools for measuring biological aging.

**Site:** [aaditya-site-zeta.vercel.app](https://aaditya-site-zeta.vercel.app) · **LinkedIn:** [aaditya-geddam](https://linkedin.com/in/aaditya-geddam)

## Projects

- **[LabAge](https://labage.vercel.app)** ([code](https://github.com/aadityageddam-ux/labage)): exploratory Phenotypic Age calculator with survey-weighted NHANES fasting-glucose references.
- **[phenoage-calc](https://github.com/aadityageddam-ux/phenoage-calc)**: Python library for the Phenotypic Age calculation, with explicit CRP units and tested single and batch APIs.
- **[HallmarksExplorer](https://hallmarksexplorers.vercel.app/)** ([code](https://github.com/aadityageddam-ux/hallmarks-explorer)): educational guide to the hallmarks of aging with cited studies and stated measurement limits.
- **[NHANES Biomarker Profiles](https://aadityageddam-ux.github.io/nhanes-biomarker-dashboard/)** ([code](https://github.com/aadityageddam-ux/nhanes-biomarker-dashboard)): age- and sex-specific biomarker profiles from NHANES, with design-based confidence intervals.
- **[Lab 3: messy-data parsing](https://github.com/aadityageddam-ux/hds-lab3-messy-parsing)**: regex versus AI-assisted cleaning of messy clinical and FASTA data, scored against a ground-truth table.

These are educational and exploratory tools, not clinical software.
